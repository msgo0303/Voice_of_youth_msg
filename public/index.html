관리자 Dashboard & 주요 현황

텔레그램 메신저 환경 내에서 즉시 관리자가 설문 현황을 검토하고, 새 설문을 작성하거나 실시간 응답 상태를 트래킹할 수 있는 모바일 최적화 메인 뷰입니다.

~0.4s

UI 레이아웃
Fixed 390px

layers 컴포넌트 설계 & 아키텍처 (Next.js + shadcn/ui)

Badge / RoleIndicator

`ADMIN`, `SUPER_ADMIN`, `VIEWER` 권한에 따른 차등 컬러 칩 매핑. 관리자 뱃지는 primary-fixed 배경과 primary 텍스트를 적용하여 시각적 간섭 없이 지위를 명시합니다.

Card / SurveyStatusCard

진행 중인 설문의 경우 잔여 일자(D-Day)와 누적 응답 수, 모니터링 게이지 바를 복합적으로 노출하며 카드 내부에서 바로 [응답 보기] 및 [공유] 액션을 유도합니다.

Button / TelegramMainCTA

새 설문 생성 버튼은 48px 이상의 인체공학적 터치 영역과 active:scale-[0.99] 마이크로 햅틱 트랜지션을 통해 오작동을 차단합니다.

BottomNav / SafeInset

모바일 텔레그램 하단 내비게이션과의 충돌 방지를 위해 하단 여백 및 블러(Glassmorphism) 레이어가 처리된 고정 네비게이션 바로 구성되었습니다.

admin_panel_settings 권한 매트릭스 (Role-Based Access Control)

권한 등급 새 설문 작성 원시 응답 열람 공유 링크 생성
ADMIN (현재) 가능 전체 조회 토큰 발급 가능
VIEWER 제한됨 익명 통계만 열람 불가
SUPER_ADMIN 가능 전체 및 영구 삭제 조직 단위 승인
